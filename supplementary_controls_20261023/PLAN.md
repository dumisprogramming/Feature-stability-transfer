# Post hoc source performance baseline comparison

Recorded on 23 October 2026 after the original study and 18 October supplementary outcomes were known, before computing this comparison. This is exploratory saved-result reanalysis, not an amendment to the original confirmatory protocol.

Use the 60 preserved permutation-importance Parquet files. For every source–seed–model, extract each group's single unpermuted balanced accuracy (deduplicate its copies across 49 feature rows). Define three source-only controls without target data: population SD across actual temporal groups, population SD across matched pseudo-groups, and 1 minus mean BA across actual groups. Do not call the pseudo-group measure cross-validation variance. The same fitted detector evaluates all groups; no retraining occurs.

Use the existing role-excluded four-fold meta-regression procedure: remove the held-out dataset from both training source and target roles; average training losses across two targets and test losses across three. Fit ordinary least squares with an intercept and two model indicators; use training-only population standardisation. Retain seven specifications: model only; model plus both primary warnings; model plus temporal SD; model plus pseudo-group SD; model plus mean source error; model plus all three controls; and all three controls plus both primary warnings. Report pooled and per-dataset MAE and RMSE. Retain all outputs without tuning, prediction clipping, significance tests or confidence intervals. Positive improvement equals baseline MAE minus candidate MAE. Repeat after deleting each seed. Verify source input hashes against each stability record, equal group sample sizes, within-group constant BA and means against the preserved warning-score CSV. Independently reproduce predictions with NumPy least squares and test held-out outcome/scaling isolation. The limited four-dataset dependence remains.

Do not infer model disagreement from aggregate scores. Raw common-row predictions and source feature panels are unavailable in this package, so disagreement and feature-distribution heterogeneity cannot be calculated faithfully. Independent dataset expansion, attack-family transfer and temporal-width sensitivity also require missing original data/model prerequisites and remain outstanding.
