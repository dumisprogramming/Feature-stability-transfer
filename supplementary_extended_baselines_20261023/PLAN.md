# Additional source-only warning comparison — 23 October 2026

This plan is recorded after the original results and the earlier performance-control comparison were known, but before fitting the comparisons in this folder. It is post hoc, not confirmatory. Source prediction and panel schemas, hashes and row alignment have already been inspected.

Use all four original datasets, five original seeds and three original models. Preserve all archived inputs. No new IDS fitting, threshold selection or target-informed warning selection.

1. Model disagreement: for each source-dataset/seed/model, on the saved source-test panel, average its binary prediction disagreement with each of the other two models. Require identical unique row identifiers and source labels across models. Use saved calibrated binary predictions, without changing thresholds. Calibration predictions are verified but not used to construct this warning.
2. Source feature heterogeneity: on the saved source environmental panel, calculate the total-variation distance (half the sum of absolute frequency differences) for every unordered pair of actual environments, separately for each of 49 features. Average equally over features and environment pairs. For numeric features, use up to ten bins with internal decile edges from the pooled SOURCE panel; repeated edges removed. For the explicitly listed categorical codes, use exact category frequencies. Missing/nonfinite values have a separate category. The label column is never used. No target data determine bins. This model-independent warning is repeated across models within a source/seed.
3. Categorical feature list: L4_SRC_PORT, L4_DST_PORT, PROTOCOL, L7_PROTO, TCP_FLAGS, CLIENT_TCP_FLAGS, SERVER_TCP_FLAGS, ICMP_TYPE, ICMP_IPV4_TYPE, DNS_QUERY_ID, DNS_QUERY_TYPE, FTP_COMMAND_RET_CODE. All other predictors use source-pooled decile bins. This grouping is a post-hoc analysis choice, not a recovered original protocol requirement.
4. Six fixed OLS specifications: model identity only; identity plus original two primary warnings; identity plus disagreement; identity plus heterogeneity; identity plus both additional warnings; identity plus both additional and both primary warnings. No tuning, clipping or choosing a winning subset for reporting.
5. Strict role-excluded leave-one-source-dataset-out evaluation: exclude the held-out dataset from both source and target roles in training outcomes. Average training loss over the remaining two targets, testing loss over three targets. Standardize covariates on training units only. Include all five leave-one-seed-out repetitions. Report pooled and per-dataset MAE/RMSE, not significance tests or population superiority.
6. Checks: archive CRC, individual historical prediction/panel hashes, unique and aligned row IDs, 49-feature schema, 4,000 rows per actual environment, all six model specifications, OLS rank, independent NumPy calculation, and agreement of shared specifications with the earlier strict comparison if supplied.

Limits: four datasets; shared remaining target datasets across folds; training/test outcome averages involve two/three targets; no independent dataset replication. Fixed-model validation predictions do not provide genuine cross-validation variance. Marginal binned feature heterogeneity omits joint dependence and may be sensitive to bins and high-cardinality categorical features. Disagreement requires access to all three fitted models' source predictions. All original panels are class-balanced; these results do not assess operational attack prevalence or attack-family transfer. New raw-data temporal partitions remain outside this analysis.
