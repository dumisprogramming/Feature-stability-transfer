# Full temporal grouping sensitivity plan

This is post hoc after original target outcomes, prior supplementary comparisons and a one-source timing pilot were known. Record this plan before new full-run importance calculations. Preserve all original artifacts.

Scope: four original NetFlow-v3 source datasets, seeds 2027–2031, three original fitted classifiers, 49 predictors, unchanged source preprocessors and source thresholds. No detector retraining. Reuse the same saved environmental rows: merge original six-hour UTC block identifiers into aligned 12- and 24-hour groups, retaining every row. No exact timestamps are recovered, no shorter intervals are evaluated and no new raw-flow panels are sampled. Different group counts, group sizes and precision are part of this bounded regrouping sensitivity; it does not establish optimal temporal resolution.

Before each model is used, verify historical hashes and schema, replay its full source-test probabilities within maximum absolute 1e-7 and identical binary predictions, and replay the first original six-hour environmental importance group with original random states. Require three-repeat importance agreement within 1e-8 and baseline balanced-accuracy agreement within 1e-12. Record actual software and load warnings. Resume only with identical software/code/plan/input identity. Empirical replay is numerical compatibility evidence, not proof of unrestricted cross-version portability.

For each width, construct pseudo-groups by deterministic within-class shuffling of the original environmental rows, preserving each actual group's exact size and benign/attack counts. All original groups contain at least 2,000 observations per class. Seed pseudo-shuffling from source dataset, seed and a canonical actual-membership fingerprint, not nominal width. Thus identical actual partitions receive identical pseudo-partitions. For each model and group, calculate all 49 permutation importances with three repeats and n_jobs=1 outside the original estimator. Seed the permutations from dataset, seed, model, partition type and the ordered selected-row fingerprint, not width. Cache identical row sets under the same model/partition. Do not import pilot scores because the full procedure uses these canonical random states.

At each width and source-seed-model unit, mean pairwise Spearman rank correlation over all group pairs defines environmental and sampling stability; ties receive average ranks and constant rank vectors contribute zero. Do not weight pairs by group size. Environmental instability is 1 minus environmental stability; sampling instability is 1 minus sampling stability; the gap is sampling stability minus environmental stability. Record undefined correlations, group counts, pair counts and class sizes. Keep negative importance/gap values. With only two groups, one pair is still reported and explicitly has limited sensitivity. Retain all source/model results regardless of direction.

Use the historical six-hour scores unchanged as baseline. Their original random assignments and importance random states differ from the new canonical procedure; contrasts against six hours therefore also contain Monte Carlo differences. The 12-/24-hour CSE-CIC-IDS2018 memberships are identical in the audit and must give exactly equal scores. These are not independent sensitivity replications. Save/hash all source warnings before reading the saved transfer-loss table for the following analysis. This ordering is a record of this post-hoc calculation, not a historical pre-label freeze.

Predictive analysis: at each width (6, 12, 24 hours), retain six fixed ordinary least-squares specifications: mean only, model identity only, identity plus sampling instability, identity plus environmental instability, identity plus gap, identity plus both primary warnings. Exclude the held-out dataset from both source and target roles in meta-regression training. Training losses average two targets and testing losses three. All-seed folds contain 45 training and 15 testing units. Include all five seed-deletion runs, with 36/12 units per fold. Fit continuous scaling only on training units. No tuning or prediction clipping. Report all pooled and per-dataset MAE/RMSE results; positive improvement is model-only MAE minus candidate MAE within the same width/run/fold. Verify the historical six-hour model-only and primary-warning MAEs against prior saved analyses. Independently check OLS predictions with NumPy. Report rank deficiency if any; do not silently remove predictors or claim a full-rank pass.

Report descriptive Spearman correlations on the 12 source-model units at each width, with no new hypothesis tests, p-values, confidence intervals, power or equivalence claims. No predictive superiority is established from these overlapping folds. This work does not address independent new datasets, natural attack prevalence, attack-family transfer or genuine refitted cross-validation variance.

Checkpoints: write each group atomically with a payload checksum and code/software/input identity. Verify completed checkpoints before reuse. Keep partial progress on Drive, with a single runtime writing a run folder. Store all calculations separately from frozen folders. A full pass requires all group references and 180 source-seed-model-width scores, 432 meta-regression fits and 5,400 OOF predictions. The archived raw pipeline is not reproduced by this run.
