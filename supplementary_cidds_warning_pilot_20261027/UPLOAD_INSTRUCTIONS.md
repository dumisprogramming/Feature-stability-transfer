# Upload the S20 support folder

1. Extract the outer support ZIP on your computer.
2. Open the Feature-stability-transfer repository main page on GitHub.
3. Select Add file → Upload files.
4. Drag the complete `supplementary_cidds_warning_pilot_20261027` folder into the upload area. Preserve its folder name and subfolders.
5. Keep the original report under `archives/` zipped. Do not unpack its hundreds of internal checkpoint files into the web uploader.
6. Review the selected paths and commit with the summary `Add verified CIDDS supplementary pilot S20`.
7. Return the commit or folder URL for public byte verification.

Do not replace the earlier S19/S18 folders or upload raw Drive datasets, candidate cohorts or partition matrices. This package contains fewer than 100 files. The manuscript, reviewer response, author approval and persistent release are separate from uploading this support folder.
